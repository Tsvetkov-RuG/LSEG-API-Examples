# LSEG-API-Examples

This repository provides working examples to collect data from LSEG API for academic research. 
See also LSEG-API-Samples repository https://github.com/LSEG-API-Samples/ and in particular
https://github.com/LSEG-API-Samples/Example.DataLibrary.Python/

## License and app key

You need a license to access LSEG. Request it from your IT. You get a username, typically your email, and a password.

To generate an API key login to LSED Workspace and search for APPKEY. 
In the REGISTER APPLICATION screen, choose sensible name, select Eikon API, click "Register New App".

Open Configuration/lseg-data.config.json file on you computer and replace "your_very_secret_app_key" with your API key.
Replace "your_user_name" with your username and "your_very_secret_password" with your password. Do not forget to keep quotation marks.

## Warning

First time, you may need to restart your Jupyter IDE to make it work.
